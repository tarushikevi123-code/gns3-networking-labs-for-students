# Lab 02 Documentation

This directory contains the practical evidence appendix
for the Dynamic IPv6 Routing with OSPFv3 laboratory.

The documentation covers:

- GNS3 topology and IPv6 addressing
- FRRouting configuration
- OSPFv3 neighbor adjacencies
- IPv6 routing tables
- External E2 default-route propagation
- End-to-end connectivity testing
- Docker image preservation and project export
